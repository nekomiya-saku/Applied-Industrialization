# Reconstruction notes

- Source of truth for the current pass was the `Applied-Industrialization`
  1.2.7 binary release and the preserved post-recovery source tree.
- The current source snapshot contains 122 files under `src/main`.
- Recovered resources include AE2/MI hatch models, blockstates, textures,
  recipes, loot tables, translations, Productive Bees data, thread-isolation
  resources, and the Mixin configuration.
- AE2, Modern Industrialization, and Jade are compile-time integration dependencies.
- Productive Bees, ExtendedAE, and MIParallelHatch integrations remain optional.
